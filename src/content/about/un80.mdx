UN80 includes a New Humanitarian Compact, and part of the Compact is work to make humanitarian data easier to combine. The plans for that work call for shared administrative boundaries and place codes (P-codes), which COD-AB provides.

## UN80

The Secretary-General launched the <a href="https://www.un.org/un80-initiative/en">UN80 Initiative</a> in March 2025, the year the UN turned 80. With resources shrinking and needs rising, it aims to make the UN system deliver more with less. The <a href="https://www.un.org/un80-initiative/sites/default/files/2025-12/251124_UN80%20Initiative%20Action%20Plan_Corrections_For-distribution.pdf">UN80 Action Plan</a> sets out 31 work packages and 86 actions. Each package has named leads, and Member States guide the decisions.

## The New Humanitarian Compact

<a href="https://www.un.org/un80-initiative/sites/default/files/2026-02/260222_UN80-GA-Pre-briefing-materials_WP2_Final.pdf">Work Package 2</a> is the humanitarian package, led by OCHA. It sets out <a href="https://www.un.org/un80-initiative/en/shifting-paradigms-1">six steps</a> toward faster, leaner and more accountable humanitarian response, covering planning, supply chains, common services, data, humanitarian diplomacy and the division of labour between agencies.

## Humanitarian data

Humanitarian organizations use different baselines, geographic units and systems, so their data is hard to combine. In a <a href="https://www.un.org/un80-initiative/en/media/742">2025 survey</a> of more than 100 crisis-response organizations, 88 per cent named this fragmentation as a key challenge.

The Compact’s data work (Actions 20 and 24) sets up a Humanitarian Data Collaborative, so that everyone in a response can work from the same evidence. Within it, five agencies known as the UN80 Data Quint are building a common Humanitarian Data Model: <a href="https://www.unocha.org/">OCHA</a>, <a href="https://www.wfp.org/">WFP</a>, <a href="https://www.unicef.org/">UNICEF</a>, <a href="https://www.unhcr.org/">UNHCR</a> and <a href="https://www.iom.int/">IOM</a>. The <a href="https://www.un.org/un80-initiative/en/media/742">plans for this work</a> call for shared P-codes and administrative boundaries to join data across agencies.
